# 박스 목표 청산과 기존 TP1~TP5 연결

## 요약·문제 재정의

박스 내부 매매에서는 먼저 상단 저항까지의 상승을 검토한다. 박스 내부에서 매수한 가격에 박스 높이를 더한 값과, 상단 돌파 후 저항선에 박스 높이를 더한 값은 서로 다르다. 이번 구현은 이 차이를 구분하고 기존 보수적·중립적·공격적 전략의 TP1~TP5와 박스 목표의 실제 교집합을 표시한다.

## 근거와 계산 분석

Fidelity의 직사각형 차트 패턴 자료는 지지와 저항 사이 높이를 측정하고 상향 돌파 목표는 저항에 이 높이를 더하는 방식을 설명한다. 따라서 S=90, R=110이면 높이 H=20, 돌파 측정 목표 M=R+H=130이다. 90에 매수하고 110 저항에서 청산하면 차이는 20이고, 130까지 진행한다면 차이는 40이다. 130은 확정 예측이 아니라 상향 돌파 후 검토하는 측정 목표다. 원본 유튜브는 박스의 추세 전환과 실패 대응을 설명했지만 이 정확한 측정 목표 산식을 명시하지 않았으므로 일반 기술적 분석 보완으로 표시한다.

PR은 질문을 어디까지 무조건 오르는가에서 박스 유지·돌파·실패별 어떤 청산 기준을 사용하는가로 바꾸기 위해 적용했다. 관측 저항과 측정 목표의 근거 수준이 다르고 진입 가격도 별도라는 통찰을 얻었다. 지지·저항 가격대가 실제로 유효하다는 전제는 현재 박스 엔진의 접촉·반응·기간 검증에 의존하며, 사건이나 거래량 충격으로 무효화될 수 있다.

MDA는 가격과 시점, 근거 수준의 차원을 평가하기 위해 선택했다. 수평 박스 높이는 경사 채널의 기울기와 동일한 수치가 아니므로 실제 수평 박스가 검증되지 않으면 측정 목표를 산출하지 않는다. 확정 일봉 전에는 돌파를 확정하지 않는다. 관측 다음 저항은 매도 압력이 발생한 데이터이고 높이 투영은 기하학적 가정이므로 같은 저항으로 취급하지 않는다. 기존 TP 도달 확률도 원래 모델의 가격에 관한 값이며 박스 측정 목표 성공 확률로 재해석하지 않는다. 과거의 더 가까운 저항이 있으면 그 저항의 청산 근거를 우선 사용하고 더 먼 측정 목표까지 반드시 보유해야 한다는 뜻을 부여하지 않는다.

CS는 기존 가격·TP 배열을 유지하면서 박스 목표만 병기하는 최소 변경을 위해 선택했다. 각 전략의 기존 TP1~TP5와 박스 청산 구간을 비교해 겹치는 행에만 실제 교집합 가격을 표시한다. 전체 목표 범위는 툴팁에서 확인할 수 있고 일부분의 중첩을 전체 범위라고 오인하지 않게 한다. 겹치는 TP가 없으면 범위 밖으로 별도 안내하며 기존 TP를 임의로 이동하지 않는다. 독립 호출에서 기존 TP가 없는 경우 관측 목표 범위 또는 공격적 측정 목표 범위 내부를 5개 구간으로 나누어 표시한다. 이는 서로 독립적인 5개 저항 발견이 아니다. 검증된 확률·기간이 없으므로 보류한다.

보수적 청산은 주요 저항 전에 여유를 두어 되돌림 위험에 대응하고, 중립적 청산은 실제 저항 가격대에 근거한다. 공격적은 확인된 돌파 이후 다음 관측 저항을 사용하는 기존 정책을 보존하며 측정 목표는 별도 조건부 참고로 표시한다. 돌파 전에도 계산은 가능하지만 확인 대기이며 실제 활성 목표가와 동일시하지 않는다. 하단 이탈이나 상단 돌파 실패에서는 측정 목표를 비활성화한다. 현재 시세가 목표를 지나간 경우 과거 목표를 앞으로의 상승 가능 가격으로 해석하지 않는다.

이 규칙은 다음 저항에서 돌파가 실패할 수 있고 박스 높이를 채우기 전 되돌릴 수 있다는 반증을 허용한다. 이미 지난 저항, 오염된 시세, 진행 중 일봉, 분할로 보이는 비정상 가격, 기존 카드 확률의 잘못된 전이를 주요 맹점으로 검토했다. 테스트가 계산 정합성을 확인해도 상승 확률·수익률·실제 체결 품질을 입증하지는 않는다.

## 결론과 추가 탐색

높이만큼의 돌파 진행은 조건부 시나리오이고 보장값이 아니다. 실제 거래에서는 상단 저항·다음 관측 저항·돌파 유지 여부를 함께 확인하는 구조다. 후속 검토 대상은 종목·시장별 목표 도달 빈도, 재시험 실패, 거래비용과 다음 거래일 체결, 다중 박스 충돌이다.
