# 박스 미형성 시 기존 가격 표시 복원

스크린샷에서 매수 2단계와 매도 3전략이 모두 가격 보류로 표시된 원인은 `apply_box_prediction`이 박스 미형성 결과로 기존 가격 모델을 덮어쓴 것이었다.

수정 정책: 관측 박스 지지·저항 또는 확인된 추세 재시험 가격이 있으면 우선 사용한다. 해당 가격이 없고 기존 매수·매도 계산에 유효한 가격 범위가 있으면 기존 값을 조건부 참고 가격으로 유지한다. 양수·유한성·범위 순서를 검증하고 가격 출처 `legacy_estimate`를 명시한다. 매도 추정 목표는 현재가보다 높은 범위에 한정하며 공격적 목표는 돌파 확인 후 검토하는 기존 추정 가격임을 밝힌다. 무효화된 박스의 하단 이탈·확정 돌파 상태에 기존 목표를 대체 삽입하지 않는다. 기존 계산 가격도 없으면 가격 보류가 유지된다.

`market_briefing/box_prediction.py`: 기존 가격 스냅샷을 보존하고 매수 단일 구간·A/B/C 밴드·분할 단계·매도 TP 배열을 복원한다. 기존 위험 판단과 박스 미확인에 따른 진입 대기를 유지한다. 수평 박스가 없을 때 기존 종합 지지·저항까지 null로 지우지 않는다.

`api/index.py`: 기존 가격으로 복원된 매수·매도 섹션은 원래 상세 카드 렌더러를 사용한다. 박스 분석으로 실제 가격이 산출된 섹션은 박스 근거를 표시한다. 기존 제목·이모지와 매수 두 단계·매도 세 전략은 유지한다.

검증: `python -m pytest tests -q` — 609 passed, 6 subtests passed, 23.20초. 이후 단일 가격 객체의 기존 메타데이터 보존 보완에 대해 `tests/test_box_prediction.py` 9개 통과. 실제 `renderForecast` JavaScript 함수를 독립 DOM 환경에서 실행해 두 매수 카드·세 매도 카드에 가격이 출력되는 것을 확인했다. 이번 브라우저 시각 검증은 수행하지 않았으며 전체 외부 데이터 API 호출이나 실제 체결 성과를 검증한 것은 아니다.

기존 값 복원 테스트는 실제 `calc_buy_price`와 `calc_risk`의 계산 결과를 사용하며 가격뿐 아니라 밴드 개수·분할 단계·TP 배열 보존을 확인한다. 참고 가격 표시를 즉시 진입 허용이나 관측된 박스 저항으로 표현하지 않는다.
