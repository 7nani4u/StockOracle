# 코스피·코스닥 일별 방향 예측 — 검증 프로토콜 (2026-11-04, 실행 전 고정)

이 문서는 `scripts/backtest_weekly_forecast.py` 를 처음 실행하기 전에 작성했다. 결과를 본 뒤 아래 규칙을 바꾸지 않는다.

## 목표 정의
- 대상: 코스피(KOSPI), 코스닥(KOSDAQ) 지수의 거래일 t 종가가 직전 거래일 종가보다 높은지(상승) 낮은지(하락).
- 예측 거리 h: h=1 은 직전 확정 세션 다음 거래일(장 시작 전 예측), h=2~5 는 주초에 미리 내는 선행 예측.

## 데이터와 시점
- 국내: 네이버 증권 일봉(fchart) 3,000세션(2014-08~). 야후 `^KS11` 은 마지막 종가가 NaN 으로 늦게 들어와 1차 출처에서 제외.
- 해외: 야후 일봉 `^GSPC ^IXIC ^SOX ^VIX ^TNX`. 세션 날짜가 [앵커 a, t-1] 인 세션만 대상일 t 의 입력이다(뉴욕 16:00 마감 = 한국 05:00~06:00, 개장 전 확정).
- USD/KRW(야후 `KRW=X`)는 일봉 마감이 런던 자정 기준이라 겨울에는 한국 09:00 이후 확정될 수 있어 모델 입력에서 제외한다(누출 위험).
- 투자자별 수급·시장 폭(상승/하락 종목 수)은 10년 이상 일별 이력을 안정적으로 받을 공개 출처를 확인하지 못해 이번 모델에 넣지 않는다.

## 평가 방식
- 확장 창 walk-forward, 21세션마다 재학습, 최소 학습 750행.
- 학습 표본은 정답(대상일 종가)이 예측 앵커 이전에 확정된 행만 쓴다.
- 개발 구간: 대상일 ≤ 2021-12-31. 보류 구간: 2022-01-01 이후.
- 후보: 특징 집합(overnight_full / overnight_compact / kr_only) × 릿지 α(3, 30, 300) × 확률 방식(경험적 잔차 / 정규 근사), 로지스틱(α=30), 기준 모델(기저 상승률).
- 선택 규칙: 지수·예측 거리별로 **개발 구간 Brier 최소**. 기준 모델도 후보이며, 아무 후보도 기준보다 낫지 않으면 기준 모델을 쓴다.
- 보고: 보류 구간의 적중률, 다수 클래스 적중률, Brier·Brier skill, log loss, AUC, 클래스별 Precision/Recall/F1, 보정 구간, 확신 구간별 적중률, 수익률 MAE·80% 범위 포함률, 국면(상승장/하락장/횡보·전환, 변동성 확대)·요일·연도별 성능.
- 판단 유보: |p − 0.5| ≤ 0.05 (고정).
