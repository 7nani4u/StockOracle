# 기존 A/B/C 밴드에 박스 구간 병기

기존 1차 탐색·2차 본 진입 각각의 밴드 A/B/C 및 1~5단계 가격·확률·기간·비중 값을 보존한다. 박스 분석을 이유로 기존 밴드 가족을 단일 밴드로 교체하지 않는다.

각 단계 가격 범위와 해당 박스 진입 구간의 교집합을 `box_entry_overlap`으로 계산한다. 겹치는 경우 기존 가격 아래에 박스 지지 탐색 또는 지지 반등 본 진입과 교집합 가격을 함께 표시한다. 기존 단계의 확률은 기존 모델 값이며 박스 반등 성공 확률로 재해석하지 않는다. 밴드별로 박스 전체 범위와 진입 조건도 표시하고, 단계가 겹치지 않으면 명시한다. 임의로 단계를 이동시켜 겹치게 하지 않는다. 기존 밴드가 없는 독립 호출에서는 기존 보조 구간 생성 경로를 유지한다.

수정 파일: market_briefing/box_prediction.py, api/index.py, tests/test_box_prediction.py. 화면의 누락된 ATR 근거가 undefined로 노출되는 문제도 기본 설명으로 수정했다.

검증: 실제 renderForecast 함수 독립 실행에서 6개 A/B/C 카드·30개 단계 행·박스 설명 병기·undefined 미노출 확인. Python 컴파일 통과. 단계별 교집합과 기존 범위 보존, 입력 객체 불변성 회귀 테스트 추가.
