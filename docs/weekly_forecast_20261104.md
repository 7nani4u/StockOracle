## 2. 데이터와 시점

- 국내 지수: 네이버 fchart 일봉(3,000세션, 2014-08~). 같은 시각 야후 `^KS11`·`^KQ11` 은 11-03 종가가 NaN 이었다.
- 해외: `^GSPC ^IXIC ^SOX ^VIX ^TNX`. 대상일 t 의 입력은 세션 날짜 ∈ [직전 국내 세션 a, t−1] 인 미국 세션의 누적 변화다. 미국 막대는 뉴욕 16:30 이 지나야 확정으로 본다(서머타임 반영, 한국 05:30/06:30).
- 제외: USD/KRW(야후 마감이 겨울에 한국 09:00 이후일 수 있음), 투자자별 수급·시장 폭(장기 일별 이력 출처 미확인).
- 달력: `holidays.KR` 의 public+bank 범주, 연말 휴장일(12월 마지막 평일), 2026년부터 제헌절. 12년 3,000세션 실제 기록과 불일치 0건. 임시 휴장은 환경변수 `STOCKORACLE_KRX_EXTRA_HOLIDAYS`.

## 3. 백테스트 결과(보류 구간 2022-01-03 ~ 2026-11-03, 개발 구간에서만 선택)

장 시작 전 예측(h=1, 미국 마감 반영) — 선택: 릿지[overnight_compact, α=300] + 경험적 잔차 분포(두 지수 같음)

| 지수 | n | 적중률(95% CI) | 다수 클래스 | 미국 방향 단순 규칙 | Brier(기준/미국 규칙) | AUC | 80% 범위 포함 |
|---|---|---|---|---|---|---|---|
| 코스피 | 1181 | 66.2% (63.5~68.9) | 54.5% | 65.3% | 0.214 (0.248 / 0.226) | 0.715 | 81.0% |
| 코스닥 | 1180 | 58.8% (56.0~61.6) | 52.2% | 59.9% | 0.235 (0.250 / 0.241) | 0.643 | 79.2% |

- 클래스별 F1: 코스피 상승 0.70·하락 0.61, 코스닥 상승 0.66·하락 0.49(하락 재현율 0.41).
- 확신 구간별 적중률(|p−0.5|): 코스피 <5%p 52%, 5~10 63%, 10~20 67%, ≥20 82%. 코스닥 <5%p 46%, 5~10 57%, 10~20 67%, ≥20 73%.
- 국면별(앵커 시점 정보로 분류) 코스피: 상승장 66.1%·하락장 66.1%·횡보 67.0%, 변동성 확대 65.5%. 코스닥: 58.1%·58.2%·61.5%, 변동성 확대 57.4%.
- 요일별 약점: 코스피 수요일 Brier skill 0.079, 코스닥 화요일 0.003(기준과 거의 같음).
- 수익률: MAE 코스피 1.096%p(0% 예측 1.208), 코스닥 1.289%p(1.364).

정직한 해석
- 코스피는 미국 방향만 따르는 규칙보다 적중률이 조금 높고(+0.9%p, 신뢰구간 안) 확률 품질은 확실히 낫다.
- 코스닥은 **적중률이 미국 방향 단순 규칙과 비슷하거나 약간 낮다**. 개선은 확률 품질(Brier)에 한정된다.
- 2~5거래일 앞(주초 선행 예측)과 미국 장 마감 전(h=1 잠정) 예측은 국내 기술적 지표(모멘텀·이동평균·RSI·거래량·변동성)·요일만으로는 개발·보류 구간 모두 기저율보다 나빴다 → 기저율을 그대로 표시하고 방향은 '판단 유보'.

장중 수정 예측(나우캐스트, 야후 5분봉 60거래일; 앞 30일로 scale=0.8 선택, 뒤 30일 보고)
- 코스피 Brier: 09:30 0.218 → 12:00 0.105 → 14:30 0.089. 코스닥: 0.118 → 0.090 → 0.044.
- 방향 적중률은 '현재 부호' 규칙과 같다(구조상 동일). 표본이 시점당 30일이라 참고 수준.

## 4. 예측 종류와 원장 규칙

| 종류 | 시점 | 모델 |
|---|---|---|
| 장 시작 전 예측 | 미국 마감(한국 05:30/06:30) ~ 개장 | 릿지(검증된 유일한 모델) |
| 잠정 예측 | 다음 거래일이지만 미국 장 미마감 | 기저율 |
| 선행 예측 | 2거래일 이상 앞 | 기저율 |
| 장중 수정 | 정규장 중 | 현재 등락 + 남은 시간 확산(별도 기록) |
| 실제 결과 | 마감 +15분 이후 일봉 | 확정값(시세 기준 값은 '잠정'으로 표시 후 교체) |

- `first` 불변, `final` 은 장 시작 시각에 고정(실시간 장 시작 전 예측이 없으면 재구성 + `reconstructed`), 적중은 `final` 로만 계산, 재구성분은 실시간 기록과 따로 집계.
- 원장: `datasets/weekly_forecast_state.json`(Vercel 은 `/tmp`, 환경변수 `STOCKORACLE_WEEKLY_STATE`). 이전 초안 형식 파일은 자동 백업(`.schema1.bak`).

## 5. 갱신

- 화면: 장중 5분, 미국 마감~개장 전 10분, 장 마감 후~18시 10분, 그 외 30분. 탭이 숨겨지면 멈추고 돌아오면 갱신. 🔄·당겨서 새로고침 연동.
- 서버: 로컬 서버는 같은 주기의 백그라운드 갱신 스레드(`STOCKORACLE_WEEKLY_SCHEDULER=0` 으로 끔), Vercel 은 매시 `/api/cron` 이 원장 갱신.
- 실패 시 마지막 정상 결과를 '오래된 데이터'로 표시(CDN 캐시 금지), 결과가 전혀 없으면 오류 상태 — 예측값을 만들어 채우지 않는다.

## 6. 함께 고친 기존 결함

1. 초안 주간 예측: 표준화 없는 로지스틱이 확률을 8%/92% 로 포화(Brier 0.36/0.44 > 기준 0.23/0.25), 화면 JS `d is not defined` 로 섹션 미표시, 야후 지연으로 11-03 결과 누락 → 전면 교체.
2. 시장 현황 장 상태: 야후 `^KS11` 날짜(한 세션 지연)만으로 정상 거래일을 '휴장 또는 데이터 미갱신'으로 표시 → KRX 달력 판정, 두 세션 이상 지연만 미갱신 표시. 공휴일·연말 휴장·수능일 지연 개장 반영.
3. 홈 화면 당겨서 새로고침이 아무것도 다시 불러오지 않던 문제 → 시장 현황·업종 흐름·주간 예측 갱신.
4. 업종별 흐름: 등락률 없는 골격만 보이는데 '표시 데이터 유지'로 안내 → '등락률 미수신' 표시 + 1회 자동 재시도.

## 7. 한계·후속

- 장중 수정·장 시작 전 전환은 단위 테스트(합성 시세)로만 검증했고, 실제 장중 화면은 이번 작업 시각(01시대)에 확인하지 못했다.
- 실시간 원장 적중률은 오늘부터 쌓인다. 화면의 월·화 결과는 재구성 예측이다.
- 수능일 표는 2023~2026 만 들어 있다(매년 추가 또는 `STOCKORACLE_KRX_LATE_OPEN_DAYS`).
- 후보 개선: 미국 선물(ES=F·NQ=F) 07시 값, 수급 데이터 이력 확보 후 재평가 — 같은 프로토콜로 새 기간에서 검증할 것.
