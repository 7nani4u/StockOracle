# 1차·2차 매수 구간 / 방향 확률 / 레짐 라벨 점검 (2026-10-09)

요청: ① 어떤 종목이든 `⚡ 1차 탐색 구간 · 소액 테스트`와 `📍 2차 매수 구간 · 본 진입`이 항상, 상세하고 정확하게 출력될 것
② 방향 확률의 실현 빈도 보정 여부 ③ `build_prediction_outlook` 의 이중 가산 ④ 레짐 라벨 분리.

모든 수치는 52종목(KRX 26·US 26)·2022-10~2026-09 일봉을 서비스와 같은 입력(최근 252봉)으로 시점마다 다시 계산하고,
이후 거래일의 실제 결과와 비교한 워크포워드 결과다. 재현: `scripts/audit_entry_bands.py`, `scripts/audit_prediction_layers.py`,
`scripts/fit_probability_calibration.py` (README 참조). 요약 JSON: `docs/backtests/entry_band_audit_summary.json`,
`models/probability_calibration.json`.

## 1. 구간이 "표시 보류"로 사라지던 원인

| 구분 | 이전 | 원인 |
|---|---|---|
| 2차 구간 전부 보류 | 시점의 약 29% | 하락·붕괴 구간에서는 현재가 아래에 서로 다른 가격 근거 2종이 겹치는 곳이 없는 것이 정상인데, "근거 부족 → 가격 삭제"로 처리 |
| 1차 구간 전부 보류 | 시점의 약 5% | 밴드 폭이 4~5호가인 저가주에서 4·5단계가 같은 호가로 겹쳐(예: 112~116원 → 4·5단계 모두 112원) 단계 순서 검증 실패 → 밴드 전체 삭제 |
| 단계 가격이 밴드 밖으로 1호가 이탈 | 미국 호가 정렬 가격의 약 9% | `_round_market_price` 가 `4.26/0.01 = 425.99999999999994` 처럼 부동소수점 오차로 floor 에서 한 호가를 더 내림(ceil 은 2.3%) |

수정은 검증을 우회하지 않고 원인을 고쳤다.

- **항상 표시 + 근거 등급.** 계산된 범위는 항상 3밴드×5단계로 내보내고, 밴드마다 `evidence_level`(구조: 서로 다른 가격 근거 2종 이상 겹침 / 단일 지표 / 변동성 기반 추정),
  `evidence_note`, `nearest_reference`, `reach_probability_range_pct` 를 붙인다. 제목은 신규상장에서도 바뀌지 않는다("관찰 전용" 칩만 추가).
- **단계 가격 충돌 제거.** `_build_buy_steps` 가 위에서 아래로 밀어 내린 뒤 아래에서 위로 한 번 더 밀어 폭 ≥ 4호가인 밴드는 항상 5개의 서로 다른 호가를 갖는다.
- **순서 복구.** 그래도 검증이 실패하면 가격을 지우는 대신 `_restack_family` 가 원래 폭을 유지한 채 한 호가씩 아래로 옮겨 A>B>C 단계 순서를 복구한다.
- **호가 반올림.** `_snap_tick_units` 로 정수에 부동소수점 오차만큼 가까운 값은 정수로 맞춘다(US 정렬 가격 99,900개 중 floor 9,126개·ceil 2,290개가 바뀌던 것이 0개).

검증 (불변식: 3밴드×5단계, 단계 가격 서로 다름·밴드 안·내림차순, 밴드 간 A>B>C, 2차<1차, 확률·기간 존재):

| 표본 | 시점 | 오류 | 위반 | 2차가 1차와 분리 안 됨 |
|---|---|---|---|---|
| 252봉 창, 52종목 | 6,419 | 0 | 2건 (ATR 12~14% 극단 변동성에서 2차 B·C 가 현재가 10% 하한에 동시에 닿아 밴드 순서 완화, `ordering_relaxed` 표시) | 0 |
| 짧은 이력(23~252봉부터, 2021-11~) | 12,657 | 0 | 3건 (같은 유형) | 0 |

## 2. 단계별 도달 확률·예상 기간 재설계

이전 방식은 최근 180개 시작일의 ATR 정규화 낙폭 경로에 임의 가산(`model_adjustment`)을 더했다. 같은 단계들에 대해 이후 30거래일 안에 저가가 단계 가격에 닿았는지로 검증했다(187,110 단계):

| | 표시 확률 (이전) | 변동성 터치 모델 (현재) |
|---|---|---|
| Brier (상수 예측 0.2468) | 0.2132 | **0.1900** |
| AUC | 0.733 | **0.785** |
| 표시 ≤5% 구간의 실제 터치율 | 19.5% (표시 평균 1.6%) | 1.5% (표시 평균 2.3%) |
| 표시 95~100% 구간의 실제 터치율 | 83.1% (표시 평균 98.6%) | 92.1% (표시 평균 97.5%) |
| 두 값을 로지스틱 결합한 가중치 | −0.08 (정보 없음) | 1.05 |

기존 값을 섞어도 정보가 늘지 않아(결합 가중치 −0.08) 하나로 통일했다. `probability_low/high_pct` 는 변동성 추정 오차의 중간 50%
(이후 30일 실현 변동성 ÷ 예측 σ 의 25·75 백분위 = ×0.836 / ×1.268, 중앙값 1.02 로 편향 없음)를 도달 확률에 옮긴 범위다.

예상 기간은 같은 분포의 첫 통과시간을 "기간 안에 닿는 경우"로 조건화한 25~75 백분위다(`touch_time_window`).
실제 첫 도달일이 창에 들어온 비율 63.96%(이전 63.7%)에 평균 폭 8.7일(이전 11.1일)로, 같은 포함률에 더 좁다. 창보다 늦게 닿는 경우가 25.7%, 일찍 닿는 경우가 10.4%다.

**알려진 한계.** 이 표본 기간은 상승 추세가 뚜렷했다(30거래일 평균 수익률 +3.5%, 상승 비율 56.7%). 무추세 모형은 그 결과
하락 방향 터치를 평균 4~7%p 과대평가하고 상승 방향 터치를 6%p 과소평가한다(표 밖 대칭 점검: 하락 +4.4%p / 상승 −6.3%p, 모든 연도에서 같은 부호).
장기 기대수익 가정(예: 일 +0.04%)을 넣으면 두 편향이 절반 정도로 줄지만(Brier −0.0015~−0.003) 하락장 분기에서는 오히려 나빠져
표본에 맞춘 상수를 넣지 않고 무추세 모형을 유지했다. 하락장에서는 깊은 단계의 도달을 과소평가할 수 있다.
2021-11~2022 하락 구간이 더 많이 들어간 짧은 이력 표본(370,350 단계)에서는 예측 평균 49.0% 대 실제 47.2% 로 편향이 1.8%p 에 그치고 Brier 0.188(상수 0.249)·AUC 0.787 이어서, 편향의 크기가 시장 국면에 따라 움직인다는 점을 뒷받침한다(`docs/backtests/entry_band_audit_short_history_summary.json`).

## 3. 방향 확률 보정 (결정: 보정한다)

| 표본 밖(2024-07-25 이후, 4,524 시점) | Brier | ECE |
|---|---|---|
| 보정 전 `prob_final` | 0.2752 | 0.1315 |
| 보정 후 | **0.2446** | **0.0438** |
| 시장별 기저 상승률 상수 | 0.2444 | – |

- 표시 확률은 `시장별 절편 + 기울기×(p_raw − 0.5)` 로 보정한다. 기울기 0.037, 블록 부트스트랩 95% 구간 −0.055~0.135 → 0 을 포함한다. 규칙 점수가 22거래일 방향을 구분한다는 증거가 없고, 보정 후 확률은 기저 상승률(KRX 약 55%·US 약 58%) 부근에 모인다.
- 시장별 기울기는 학습/검증 구간에서 부호가 뒤집혀(KRX −0.31 → 검증 AUC +0.56) 채택하지 않았다.
- 원래 값은 `prob_up_raw`(신호 점수)로 남기고 화면에는 보정 전 점수를 작게 함께 보여 준다. 보정 파일이 없으면 원래 값을 그대로 쓴다.

## 4. `build_prediction_outlook` 이중 가산 제거

`direction_adjust` 는 점수·수급·패턴·시장 체제·전일 등락·거래량·RSI·이벤트를 확률에 다시 더했다. 이미 같은 정보가 `prob_up` 입력(점수·상관 보정)에 들어 있고,
가산된 시나리오 비중은 AUC 0.500·Brier 0.296 으로 더하기 전(0.511·0.273)보다 나빴다. 방향 확률을 실현 빈도에 맞추면 ±10%p 가산은 보정을 다시 무너뜨리므로 제거했다.
그 요인들은 상승 요인/하락 위험 문장에만 남는다.

`주의·매수 보류` 의 `하락 비중 ≥ 48%` 조건도 근거가 없었다. 하락폭(8%↑) 예측력은 거의 전부 변동성이고
(AUC 0.691), 변동성 3분위 안에서는 점수·확률·하락 비중·레짐 모두 0.49~0.51 이다.

| 변수 | AUC (8%↑ 하락) | 변동성 3분위 내 평균 AUC |
|---|---|---|
| 변동성(P10~P90 폭) | 0.691 | 0.578 |
| `-prob_l0` | 0.587 | 0.512 |
| 하락 시나리오 비중(이전) | 0.557 | 0.501 |
| `-score` | 0.509 | 0.487 |

남은 트리거는 구조 이탈 2건 이상·이벤트 위험 60점 이상·붕괴 대기 신호다.

## 5. 레짐 라벨 분리

단일 종목 분석은 하이브리드 점수에 벤치마크를 넘기지 않아 "시장 국면" 배지가 사실은 종목 자신의 ADX·DI 로만 판정되고(5점 기준에 닿지 못해 항상 횡보),
예측 탭은 지수의 60·120일선 구조를 "종목 중기 구조 · 해당 종목의 60일·120일 가격 구조"라고 불렀다. 이제 세 가지를 이름으로 나눴다(`regime_layers`).

| 이름 | 값 | 비고 |
|---|---|---|
| `KOSPI/KOSDAQ/S&P 500 중기 구조 (60·120일선)` | 상승 구조 / 하락 구조 / 혼조 | 점수 상한(BEAR ≤ 40)·매수 밴드 깊이·신뢰도의 시장 점수 |
| `시장 장기 국면 (200일선·ADX·VIX)` | 강세장 / 약세장 / 횡보장 | 스캔 머리말(벤치마크 있을 때) |
| `종목 추세 (ADX·DI, 시장 기준 미적용)` | 상승 추세 / 하락 추세 / 방향 불명 | 단일 종목 복합 기술 신호 카드 |

두 값이 같은 날 엇갈리면(`BEAR` ↔ `BULLISH`) `regime_layers.note` 가 서로 다른 기준임을 알린다.
단일 종목 분석에서 시장 장기 국면을 실제로 계산하려면 벤치마크·VIX 를 하이브리드 점수에 넘겨야 하며, 점수 상한이 바뀌므로 이번에는 라벨만 분리했다.
