PR을 먼저 선택한 이유는 주가 방향을 맞추는 문제와 진입 가능한 신호를 만드는 문제가 다르기 때문이다. 관측 지지선, 조건부 변동성 범위, 모델의 방향 클래스 확률은 서로 대체 가능한 값이 아니다. 예측 범위가 유효하더라도 현재가가 진입 밴드 밖에 있거나 종합 판단이 주의라면 주문 후보는 보류되어야 한다. 이 분석은 예측 결과를 실행 조건과 분리할 수 있다는 가정에 의존한다. 반대로 사용자가 하나의 점수만 원하더라도 서로 다른 의미의 숫자를 단순 평균하면 오류를 감출 수 있으므로 단일 숫자로 재통합하지 않았다.

MDA를 두 번째로 적용한 이유는 시간, 시장, 데이터 층위가 동시에 작동하기 때문이다. 영상은 분봉과 호가창을 설명하지만 시스템은 주로 일봉을 소비한다. 일봉의 시가 다음에 고가·저가 중 무엇이 먼저였는지는 알 수 없다. 따라서 시가로 이미 목표나 손절을 넘은 사건은 먼저 처리하고, 이후 봉 안에서 목표·손절이 모두 닿으면 손절 우선으로 평가한다. 이는 경로를 복원한 사실이 아니라 보수적 체결 가정이다. 한국·미국의 비용과 거래 시간도 다르므로 하나의 비용을 실제 시장 비용이라고 고정하지 않고 CLI 입력으로 분리했다. 변동성·확률의 수학적 정합성이 좋아져도 실제 데이터 공급자의 조정주가 오류나 시세 지연까지 사라지지는 않는다는 제약이 있다.

IA는 기존 테스트의 통과를 반증하기 위해 선택했다. 다음 날 시가가 95, 원래 기준가가 100, 손절이 90, 목표가 110·120인 사례에서 기존 감사는 1.5R을 출력했으나 실제 진입 위험은 5이므로 절반씩 청산한 결과는 4R이다. 갭 하락 시 손절 90을 건너뛰어 80에 개장하면 손실은 원래 100 진입 기준 −2R이며 −1R이 아니다. 이는 성과가 항상 나빠져야 정확한 수정이라는 전제를 반박한다. 정확한 체결은 유리한 진입 갭의 수익도 더 크게 계산할 수 있다. 따라서 수정 후 평균 R 상승을 전략 개선으로 해석하지 않았다.

CS는 차단 순서 문제를 해결하는 데 적용했다. 기존 box_prediction은 위험 게이트를 적용한 뒤 돌파 플랜을 새 사전으로 덮어써 진입 허용을 되살렸다. 후보를 먼저 생성하고 위험 차단을 마지막에 적용하며, 화면이 직접 읽는 tactics.plan과 summary도 같은 보류 상태로 정합화했다. 독립된 정상 돌파 양성 대조는 계속 진입 가능해야 하므로 전부 차단하는 방식으로 테스트를 통과시키지 않았다. 원시 규칙 감사는 서비스의 전체 맥락 위험 게이트를 포함하지 않으므로 보고서에 그 경계를 명시했다. 시계열 인과성만 확보했다고 서비스 결과까지 동일하다는 결론을 내리지 않았다.

ML에서는 세 가지 층위가 발견됐다. 출처·승인 누락을 명시적 거부와 동일하게 처리하지 않는 로딩 문제, 짧은 이력에서 상승·하락 값 합계가 0.96 또는 1.04가 되는 계약 문제, 중립 90%를 제거한 나머지에서 계산한 조건부 상승 90%가 행동 UP으로 노출되는 의미 문제다. 이번 수정은 원래 클래스 확률과 조건부 방향 비중을 함께 반환하고 중립 우세일 때 행동을 중립으로 제한한다. 조건부 확률을 무조건부 상승확률로 이름만 바꾸어 기존 보정 모델을 무효화하는 대안은 피했다. 이 수정 역시 모델의 외부 예측력을 증명하지는 않는다.

## ④ 개선 아이디어 10개와 적용 판단

1. **최종 위험 게이트를 단조롭게 만든다 — 적용.** 후보 생성 뒤 차단은 허용 상태를 좁히기만 해야 한다. 기존 돌파 어댑터처럼 새 사전을 만들어 승인 여부를 초기화하면, 종합 위험과 표시된 진입 카드가 서로 반대가 된다. 후보 가격은 설명 자료로 보존하되 실행 허용, 플랜 ready, 추가 매수 ready와 요약을 함께 보류하는 계약을 사용했다. 정상 돌파 양성 대조와 다섯 차단 조건을 나란히 검증했다. 추후 전략 추가 시에도 이 순서 자체를 유지해야 하며, 새 점수의 가중치 조정으로 위험 차단을 우회하면 안 된다.

2. **확률의 조건을 응답에 기록한다 — 적용.** 상승/하락만 남겨 정규화한 값은 중립을 포함한 전체 사건에서의 상승확률과 다르다. 기존 보정·소비자 호환을 위해 조건부 방향 비중을 유지하면서 원래 세 클래스 확률과 probability_basis를 추가했다. 중립이 가장 큰 클래스이면 행동 방향은 NEUTRAL이다. 단순히 확률 합계를 1로 만드는 것만으로는 이 의미 오류를 찾지 못하므로 중립 90%와 뒤집힌 classes_ 순서를 별도 테스트한다. 향후 확률 보정도 같은 사건 정의에 대해 평가해야 한다.

3. **모델 출처와 승인을 필수로 만든다 — 적용.** 검증 실패를 명시한 아티팩트만 거부하면 메타데이터가 삭제된 모델이 오히려 사용 가능해진다. validation.passed, provenance.known, synthetic_present의 명시적 상태를 검사하고 JSON 형태도 확인한 후 모델을 읽는다. 현재 기존 모델은 출처 정보가 부족하여 휴리스틱으로 전환된다. 이것은 성능 저하 여부와 별개인 근거 보존 결정이다. 자료의 출처를 복원하고 독립 검증을 끝낸 뒤 승인해야 하며 단순히 JSON 키를 추가해서 우회하지 않는다.

4. **체결가 기준 위험과 수익을 계산한다 — 적용.** 신호 시점 기준가는 주문 참고값이며 다음 시가 체결과 동일하지 않다. 실제 체결가와 손절의 거리를 R 분모에 사용하고 모든 청산의 가중 현금흐름을 합산했다. 유리한 갭과 불리한 갭을 대칭적으로 계산하며, 진입 시 이미 첫 목표를 지나면 추격 체결을 제외한다. 이 변경으로 평균 R이 오를 수도 내려갈 수도 있다. 최적화의 성공 기준은 숫자의 상승이 아니라 정의한 체결 정책과 산술 결과의 일치다.

5. **일봉의 경로 불확실성을 드러낸다 — 적용.** 개장 시 이미 시장가로 실행 가능한 손절과 지정가 목표를 먼저 처리하고, 이후 동일 봉 안의 경합은 손절 우선이다. 첫 목표 후 손절 이동은 다음 봉부터 적용한다. 같은 봉에서 목표 도달 직후 저가가 형성되었다고 임의로 가정하지 않기 위해서다. 이 정책은 실시간 거래를 완전히 재현하지 못하므로 모델에 포함된 가정을 보고서에 남긴다. 분봉 자료를 확보하면 동일 거래를 더 세밀한 순서로 재평가하는 비교 실험이 가능하다.

6. **미도달·미완료 사건을 구분한다 — 적용.** 관찰 기간이 끝났는데 목표와 손절 어디에도 닿지 않은 지지 사건은 실패도 성공도 아닌 unresolved이며 전체 도달률의 분모에는 남아야 한다. 반면 거래 자체의 보유 기간이 아직 끝나지 않은 우측 절단 자료는 실현 기간 종료 수익으로 세지 않는다. resolved_only_rate를 별도 제공해 과거 보고서의 분모와 비교할 수 있게 했다. 향후 생존 분석을 도입하더라도 기존 도달률과 명칭을 혼동하지 않도록 사건·검열 정의를 먼저 고정해야 한다.

7. **시장 비용과 중복 포지션을 검증에 포함한다 — 적용.** CLI에 왕복 비용과 편도 슬리피지를 추가하고 선택한 값을 보고서에 저장한다. 같은 종목의 기존 포지션이 살아 있는 동안 새 플랜을 별도 거래처럼 세지 않는다. 이번 .2%·.1%는 민감도 가정이며 한국이나 미국의 실제 모든 거래비용을 대표하지 않는다. 시장·거래소·계좌·주문 방식에 따라 현실적인 값을 따로 입력해야 한다. 추가 매수는 재생하지 않으므로 표본 성과를 영상의 불타기 성과로 부르지 않는다.

8. **원시 규칙과 서비스 성과를 분리한다 — 적용 범위 명시.** 현재 감사는 순수 OHLCV 규칙을 채점하며 뉴스·시세 이격·종합 판단까지 재생하지 않는다. 실제 캐시에서도 원시 ready가 서비스의 최종 게이트에서는 wait가 되는 사례가 확인되었다. 보고서 decision_basis에 이 차이를 명시했다. 다음 단계는 당시 뉴스와 수급·모델 버전까지 포함한 시점별 응답을 저장해 서비스 전체를 재생하는 것이다. 현재 자료만으로 그 누락을 가짜 중립 뉴스나 최신 모델로 메우면 검증이 다시 오염된다.

9. **큰 API 파일을 계약 단위로 점진 분리한다 — 후속 우선순위.** 3만 줄 API에서 수집·지표·화면이 섞이면 파이썬 단위 검사는 통과해도 JavaScript의 요소 삭제가 전체 렌더링을 조기 종료할 수 있다. 이번에는 삭제한 status 요소에 대한 필수 참조도 함께 제거하고 Node 기반 렌더 검사를 사용했다. 향후에는 외부 공급자, 순수 계산, 응답 조합, 프런트 템플릿을 작은 계약으로 분리하는 순서가 적절하다. 한 번에 전체를 재작성하면 기존 다수 변경과 충돌하고 원인 추적이 어려우므로 별도 단계로 남긴다.

10. **영상 가설을 연구 후보로 관리한다 — 적용·후속 혼합.** 중간선 자석, 속도, 압력은 직관적이지만 일봉 감사에서는 우위가 일관되게 재현되지 않았다. 따라서 영상의 사례를 적중 확률로 표시하지 않고, 구현에 없는 실시간 호가를 있다고 주장하지 않는다. 새 임계값을 같은 표본에서 탐색한 후 그 표본으로 검증을 선언하지 않는 것이 핵심이다. 향후에는 한국/미국과 상승/하락 국면을 나눈 미사용 기간, 거래비용 변화, 종목·월 단위 블록 추정으로 재평가해야 한다. 작은 표본의 높은 평균 수익만으로 필터를 풀지 않는다.
