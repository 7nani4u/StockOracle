# 거래량-가격 괴리 매집 탐지 설계 및 검증

- 기준일: 2026-09-30
- 적용 화면/API: `🔬 7단계 스캔 엔진`, `GET /api/scan`
- 성격: 매집 가능성을 좁히는 보조 탐지 신호이며 매집 확정 또는 매수 권유가 아님

## 탐지 규칙

| 항목 | 규칙 |
|---|---|
| 최근 구간 | 최근 20거래일 |
| 평소 거래량 기준 | 최근 구간과 겹치지 않는 직전 60거래일의 일평균 거래량 |
| 거래량 조건 | 최근 20일 일평균 / 직전 60일 일평균 ≥ 3.0 |
| 가격 조건 | 최근 구간 시작 직전 종가 대비 최신 종가 수익률의 절댓값 ≤ 3.0% |
| 최종 후보 | 거래량 조건과 가격 조건을 모두 충족한 종목만 표시 |

최근 20일을 기준 거래량에 포함하지 않아 거래량 폭증이 기준값을 끌어올려 신호를 희석하는 문제를 방지한다. 가격 조건은 기간 중 고저 범위가 아니라 시작 대비 종료의 순가격 변동이다.

## 시스템 연결

1. `market_briefing.scan_engine.detect_volume_price_divergence()`가 순수 계산과 데이터 유효성 검사를 담당한다.
2. `build_snapshot_from_ohlcv()`가 모든 수집 종목의 `TechnicalSnapshot`에 계산 결과를 저장한다.
3. `/api/scan`은 기존 QMJ·추세 필터와 독립적으로 전체 수집 스냅샷을 평가한다.
4. API의 `volume_price_divergence.candidates`에는 두 조건을 모두 만족한 종목만 담는다.
5. 화면은 일치 종목의 최근/기준 평균 거래량, 거래량 배수, 20일 가격 변동을 근거로 표시한다.

## 데이터 품질과 한계

- 최소 80개의 정렬된 OHLCV 거래일이 필요하다. 부족하면 추정하지 않고 `unavailable_count`에 집계한다.
- 결측 OHLCV는 동일 날짜 행 단위로 제거해 가격과 거래량의 날짜 불일치를 방지한다.
- 액면분할, 지수 편입, 이벤트성 블록딜, ETF 리밸런싱도 거래량 급증을 만들 수 있다.
- 가격이 기간 중 크게 움직인 뒤 원위치해도 순변동 ±3% 조건을 충족할 수 있다.
- 따라서 이 신호만으로 수급 주체나 향후 상승을 확정할 수 없으며 기존 리스크·품질 분석과 함께 확인해야 한다.
