# 박스 진입 구간을 기존 TP1~TP5 매수 표에 표시

원인: 관측 박스 가격이 존재하는 응답은 별도의 요약 카드로 렌더링되어 기존 상세 표를 우회했고, 어댑터가 생성한 매수 밴드의 steps 배열도 비어 있었다.

수정: 어댑터의 관측 박스/추세 재시험 가격대를 TP1~TP5의 매수 가격 범위로 구성하고, 기존 상세 매수 카드 렌더러를 사용한다. 1차 탐색·2차 본 진입 제목과 기존 단계·매수 가격 범위·하락률·도달 확률·예상 기간 표 구조를 유지한다.

TP1은 진입 가격대의 가장 높은 부분, TP5는 가장 낮은 부분이다. 5개 인접 구간은 해당 분석 범위의 전체를 포함하며 기존 범위를 벗어나지 않는다. 이 표시용 분할은 새로운 지지선이나 매도 목표를 생성하지 않는다. 박스 전략의 확률과 기간은 검증된 보정치가 없으므로 미산정/확인 후 진입으로 표시하고 주문 비중을 임의로 부여하지 않는다. 기존 모델 가격을 복원하는 경로에서는 기존 밴드와 단계 배열을 유지한다. 자료가 부족하면 단계 가격을 만들어 넣지 않는다.

수정 파일: api/index.py, market_briefing/box_prediction.py, tests/test_box_prediction.py, tests/test_buy_entry_steps.py.

검증: 관련 pytest 58개 통과. 실제 renderForecast JavaScript 함수를 독립 DOM 환경에서 실행해 두 매수 카드에 각각 TP1~TP5가 표시되고 총 10개 가격 행이 생성되는 것을 확인했다. 전체 회귀 실행 결과는 아래에 기록한다.
